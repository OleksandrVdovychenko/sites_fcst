# Інструкції для ШІ-агента (Claude Code / Claude Tag)

Цей файл описує, як вносити зміни в сайт ФКНТ. Дотримуйся його дослівно.

## Золоте правило
Ти **готуєш зміни й відкриваєш Pull Request**. Ти **ніколи не публікуєш напряму** в `main`.
Офіційний контент факультету публікує людина, зливаючи PR. Без винятків для тебе.

Два документовані винятки існують, але це не ти: `automation/publish-news.gs`
(Google Docs → сайт, див. `NEWS-PIPELINE.md`) і мікроадмінка новин
(`src/pages/admin/` + `functions/api/news/`, див. `ADMIN-SETUP.md`) — обидва
комітять напряму в `main` від імені автентифікованої людини (Cloudflare
Access чи власник Google-акаунта), не від імені ШІ-агента.

## Структура проєкту
- `src/styles/tokens.css` — кольори й типографіка з брендбуку. **Не** вводь нових кольорів поза токенами.
- `src/layouts/Base.astro` — спільна оболонка (шапка, меню, футер). Правиш тут — зміниться скрізь.
- `src/components/` — перевикористовувані компоненти (напр. `DepartmentCard.astro`).
- `src/data/*.json` — структуровані дані (кафедри, навігація).
- `src/content/news/` — новини (по одному `.md`-файлу на новину).
- `src/pages/` — маршрути. Файл = сторінка.

## Як додати новину
1. Створи файл `src/content/news/РРРР-ММ-короткий-слаг.md`.
2. Frontmatter має точно відповідати схемі в `src/content/config.ts`:
   ```
   ---
   title: <заголовок, до ~90 символів>
   date: РРРР-ММ-ДД
   category: Новини | Досягнення | Події | Вступ | Наука
   cover: /news/<файл>.jpg        # необовʼязково
   summary: <1–2 речення, до 240 символів>
   draft: false
   ---
   ```
3. Тіло — markdown. Заголовки від `##` (h1 — це поле `title`).
4. Тон: діловий, доброзичливий, українською. Активний стан. Без канцеляриту й вигаданих фактів.
5. **Факти, імена, дати, цифри** бери лише з наданих матеріалів. Нічого не вигадуй.
   Якщо даних бракує — постав `draft: true` і познач у PR, що треба уточнити.

## Як додати/змінити кафедру
Редагуй `src/data/departments.json` (не чіпай розмітку). Поля: `kind, type,
name, desc?, tags[]?, url?, badge?, labs?[]` (`labs` — вкладені лабораторії
кафедри, кожна `{ name, desc?, tags?[], url? }`; `desc`/`tags`/`url` теж
необов'язкові — не вигадуй їх, якщо даних нема, лишай поле відсутнім).

## Як додати сторінку
Створи `.astro` у `src/pages/...`, обгорни вміст у `<Base>…</Base>`,
використовуй наявні токени й класи. Не дублюй шапку/футер — вони в `Base.astro`.

## Перед відкриттям PR
- Переконайся, що `npm run build` проходить без помилок (схема новин валідується на білді).
- Опис PR: що додано/змінено + **чек-лист для рецензента** (що перевірити перед публікацією).
- Прикріпи, звідки взяті факти.

## Чого не робити
- Не публікувати без рев'ю. Не вигадувати цитати/статистику. Не вводити кольори/шрифти поза брендбуком.
- Не видаляти чужий контент без явного прохання.
